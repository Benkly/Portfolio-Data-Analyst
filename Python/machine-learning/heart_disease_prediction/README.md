# Heart Disease Classification Projects

These projects showcase two different models built for prediction of heart disease. Refer to the notebooks for full details.

## `kNN-model`

A conceptually simple classifier built using the k-Nearest Neighbours algorithm. 

* Typically, this algorithm is not ideal for medical applications due to challenges in interpreting the model results.

## `logistic-regression-model`

A classifier based on logistic regression which learns a mathematical relationship between features and probability of heart disease. This can be seen as an extension of the initial kNN model.

* This is far more interpretable, so is more suited to medical application.

# Portfolio-Data-Analyst

This repo contains independent portfolio projects completed as part of the Dataquest Business Analyst, Data Analyst, and Data Science courses. Each project applies analytical techniques to real-world datasets and business scenarios, demonstrating proficiency across a range of tools and methodologies.

---

## Excel Projects

Exploratory and Explanatory Data Analysis reports in business contexts, built entirely in Excel.

| Project | Description |
|---------|-------------|
| `retail-eda` | Exploratory data analysis of a retail store dataset — identifying sales trends, product performance, and customer insights. |
| `telecom-customer-churn` | Churn prediction analysis for a telecom company, exploring factors that drive customer attrition. |

Also included are example PowerPoint presentations from PhD studies showcasing data-driven storytelling and academic communication skills.

---

## Power BI

Power BI Desktop (`.pbix`) files for Business Intelligence projects focused on building semantic data models and reporting critical performance metrics through interactive dashboards.

| Project | Description |
|---------|-------------|
| `Superstore-high-level-finance-report` | A high-level financial performance dashboard for a superstore, summarising revenue, profit, and key KPIs in a visually appealing report. |

## SQL Projects

Exploratory and Explanatory Data Analysis reports in business contexts, with a focus on meeting analytical deliverables through structured query writing.

| Project | Dialect | Description |
|---------|---------|-------------|
| `customer_product_analysis` | SQLite (DB Browser) | A suite of queries covering customer lifetime value, profit per customer, proportion of new customers by month, and restocking priority. Accompanied by a summary presentation. |
| `northwind` | PostgreSQL (via Python) | Advanced SQL analysis using window functions, CTEs, and subqueries on the Northwind database. Integrated with Python for execution and visualisation, with a results summary presentation. |
